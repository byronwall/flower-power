# Intent index

Each folder holds the intent for one part of Flower Power. The product folder is the umbrella. It owns the whole flow, the audience, the first proof, and the full spike list. Each part folder owns the detail for its own area, and it links back to the product.

A part gets its own folder when it has intent that does not fit in the product brief. Until then, its intent stays in the product brief and its spikes stay in the product spike list.
