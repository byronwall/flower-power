# Intent index

Each folder holds the intent for one part of Flower Power. The product folder is the umbrella. It owns the audience, the whole flow, the scope, the first proof, and the full spike list. Each part folder owns the detail for its own area and links back to the product.

When a new decision affects one part only, record it in that part's folder. When it changes the whole flow, the audience, or the first proof, record it in the product folder too.

| Part | What it owns | Spikes | Open question |
| --- | --- | --- | --- |
| [Product](garden-design-app/intent-brief.md) | Audience, whole flow, scope, first proof, all spikes | All | None |
| [Property capture](property-capture/intent-brief.md) | Address, aerial view, AI-marked features, photos, lot lines | S1, S2, S3, S4 | Name existing plants in photos, or outline beds only? |
| [Sun and shade](sun-and-shade/intent-brief.md) | House direction, shadow check, sun class for each area | S8, S9 | Does shade change by season? |
| [Plant library](plant-library/intent-brief.md) | About 100 Indiana plants, facts, growth, gallery | S10, S11 | Natives first, or natives and popular non-natives equally? |
| [Design assistant](design-assistant/intent-brief.md) | Starting points, 3 to 5 designs, rework, yard review, reference photos | S12, S13, S14 | Does budget limit designs in the first version? |
| [Plan views](plan-views/intent-brief.md) | Watercolor 2D plan, 3D pane, height layers, time slider display | S5, S7, S15, S17 | Fixed layers or a free height slider? Steps and terraces in v1? |
| [Garden plan](garden-plan/intent-brief.md) | Shopping list, planting and care calendar | None | Do people come back over months, or take the plan once? |
| [Accounts and gallery](accounts-and-gallery/intent-brief.md) | Accounts, view-only sharing, public gallery wall | S16 | How does a person reset a forgotten password? |

Each folder has an `intent-brief.md` for people to read and an `initiative-map.json` that records claims, sources, and history.

The [overview page](https://claude.ai/artifact/LLiJW3prBD1RbqrwGhM5cB) summarizes the product for other readers.
